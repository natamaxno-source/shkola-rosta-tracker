# Техническое задание — Трекер задач «Школа Роста»

## 1. Цель проекта
Создать веб-приложение — трекер задач для команды онлайн-школы «Школа Роста». Единое пространство, где команда видит задачи, дедлайны, учеников и историю обсуждений.

## 2. Роли и права

### Администратор (владелец)
- Управляет сотрудниками (добавляет/удаляет)
- Видит все задачи и проекты
- Назначает ответственных
- Управляет настройками

### Сотрудник
- Видит свои задачи и задачи, где он исполнитель
- Комментирует задачи
- Меняет статус задач
- Видит информацию об учениках, привязанных к задачам

## 3. Экраны (MVP)

### 3.1 Авторизация
- Вход по email + пароль
- Регистрация (только для администратора приглашает сотрудников)

### 3.2 Дашборд (главная)
- Количество задач по статусам (Новые, В работе, На проверке, Готово)
- Последние обновления
- Ближайшие дедлайны

### 3.3 Проекты
- Список проектов (курсы, маркетинг, операционка)
- Карточка проекта с задачами внутри
- Создание нового проекта (админ)

### 3.4 Задачи
- Список задач с фильтрами (статус, исполнитель, проект, дедлайН)
- Карточка задачи:
  - Название
  - Описание
  - Статус (Новая → В работе → На проверке → Готово)
  - Исполнитель
  - Дедлайн
  - Приоритет (Низкий / Средний / Высокий)
  - Комментарии
  - Привязанный ученик (опционально)

### 3.5 Ученики
- Список учеников (имя, email, курсы)
- Карточка ученика с его задачами и прогрессом

### 3.6 Сотрудники (только админ)
- Список сотрудников
- Добавление / редактирование / удаление

### 3.7 Настройки профиля
- Редактирование имени, email
- Смена пароля
- Аватар (опционально)

## 4. Дизайн

Следовать брендбуку «Школа Роста»:
- Основной цвет: #1E3A5F (тёмно-синий)
- Акцент: #2ECC71 (зелёный)
- Фон: #F5F7FA
- Шрифт: Inter
- Кнопки: скругление 8px
- Карточки: белые с тенью, скругление 12px
- Боковое меню: тёмно-синий фон, белый текст, ширина 260px

## 5. Технический стек
- Frontend: React + Vite + TailwindCSS
- Backend: Express.js + SQLite (для MVP)
- Авторизация: JWT-токены
- Хранение: SQLite (файловая база)

## 6. Критерии готовности MVP

- [x] Авторизация работает (вход/выход)
- [x] Дашборд показывает статистику
- [x] Проекты: создание, просмотр, список задач внутри
- [x] Задачи: создание, редактирование статуса, назначение исполнителя
- [x] Комментарии к задачам
- [x] Список учеников
- [x] Управление сотрудниками (админ)
- [x] Настройки профиля (имя, пароль)
- [x] Дизайн соответствует брендбуку
- [x] Приложение запускается и открывается в браузере
